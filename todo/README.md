# Todo List

A todo list app built with Next.js, React, Redux Toolkit, and Tailwind CSS. Supports adding, completing, deleting, searching, and filtering todos, with a virtualized list to handle large numbers of items smoothly.

**Live demo:** [react-todo-list-jdt8.vercel.app](https://react-todo-list-jdt8.vercel.app)

## Features

- Add, complete, and delete todos
- Debounced search
- Filter by status (all / done / not done)
- Virtualized rendering for large lists

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Testing

```bash
npm run lint
npx playwright test
```
